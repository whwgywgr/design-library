# Claymorphism — Soft 3D Dashboard

Everything looks hand-moulded from plasticine: oversized radii, chunky padding, and the
signature triple shadow — a coloured drop shadow in the element's own hue, plus inset
light/shade to give real volume.

## Tokens

| Token | Value |
|---|---|
| Background | pastel gradient lavender `#c9b8ff → #ffd6e8` |
| Clay cards | pink `#ff9ec4` · mint `#90e0c8` · butter `#ffd166` · violet `#b49cf8` |
| Clay shadow | `0 22px 44px <hue 40%>, inset -10px -10px 22px rgba(0,0,0,.08), inset 10px 10px 22px rgba(255,255,255,.65)` |
| Radius | 26–34px, chunky 22px padding |
| Type | system sans, 700-weight |

## Interaction

A working morning-routine dashboard: habit rows toggle with a squish, temperature
steppers adjust the clay thermostat, and a clay progress blob fills as habits complete.

## Files

- `index.html` — self-contained, no dependencies, works offline.
