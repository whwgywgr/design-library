# Candy Pop — Playful Shop

Maximum fun per pixel: pink/mint/yellow/lilac palette, everything rounded and wobbling,
emoji products, and a cart that counts up with a confetti explosion when you buy.

## Tokens

| Token | Value |
|---|---|
| Background | `#fff6f9` soft pink-white |
| Candy palette | pink `#ff6fb5` · yellow `#ffd93d` · green `#6bcb77` · blue `#4d96ff` · lilac `#c780fa` |
| Shape language | circles + blobs, radius 20px+, everything floats |
| Type | system sans, 800-weight bouncy headline |

## Interaction

- Floating background shapes drift endlessly
- "Grab a bag" button fires a **confetti burst** (vanilla JS particles)
- Add-to-cart increments a bouncing counter badge
- Product cards wiggle on hover

## Files

- `index.html` — self-contained, no dependencies, works offline.
