# Brutalist — Creative Studio

Anti-decoration on purpose: 3px black borders, hard `8px 8px 0 #000` shadows, Arial Black uppercase headlines, a scrolling marquee and hover states that invert instead of fade.

## Tokens

| Token | Value |
|---|---|
| Ink | `#111` — borders, shadows, text |
| Background | `#fffef5` paper white |
| Accent | `#ffd400` hazard yellow (selection + hovers) |
| Shadow | `8px 8px 0 #111` (no blur, ever) |
| Type | Arial Black / system sans, uppercase, tight |

## Layout

Marquee strip → oversized studio statement → works grid (cards invert on hover) → manifesto list with numbered rows → brutal footer with giant wordmark.

## Motion

Steps instead of fades: reveals snap in, hover inverts instantly, the marquee never stops.

## Files

- `index.html` — self-contained, no dependencies, works offline.
