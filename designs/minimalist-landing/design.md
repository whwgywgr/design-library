# Minimalist — SaaS Landing

The "less is more" reference: one column of content, a single ink color, hairline dividers and no decoration that doesn't carry meaning.

## Tokens

| Token | Value |
|---|---|
| Background | `#fdfdfc` warm white |
| Ink / accent | `#141414` (buttons are ink-colored) |
| Secondary | `#8a8a8a` |
| Border | `#e8e8e6` 1px hairlines |
| Type | system sans, tight headline (-0.03em), 17px body |

## Layout

Sticky-free simple flow: nav → hero (eyebrow, headline, email capture) → 3 numbered features with rule-topped columns → oversized quote → minimal footer.

## Motion

Quiet reveal-on-scroll (opacity + 14px rise, IntersectionObserver, tiny stagger). Nothing else moves — restraint is the style.

## Files

- `index.html` — self-contained, no dependencies, works offline.
