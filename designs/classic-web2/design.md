# Classic Web 2.0 — 2005 Portal

The era between Y2K chaos and flat modernism: fixed-width centered layout, blue gradient
header with tab navigation, rounded sidebar widgets, glossy "aqua" buttons, RSS badges
and a starburst BETA sticker.

## Tokens

| Token | Value |
|---|---|
| Page background | `#d9dde3` grey-blue |
| Content panel | `#ffffff`, border `#b5bdc9`, soft shadow |
| Header / nav | gradient `#5b93d5 → #2f5f9e`, white tabs |
| Links | `#1a5299`, underline on hover |
| Sidebar boxes | `#eef3fa` on `#dce8f5` borders, 8px radius |
| Buttons | aqua gloss — `#7db2e8 → #366cae` with top highlight |
| Type | Arial / Tahoma 12–13px, Verdana small print |

## Pieces

Gradient header + tab nav → breadcrumb → sidebar (search, categories, **working poll**
with animated result bars, sponsors boxes) → article post with comments (add one!) →
footer with XHTML/RSS badges. Starburst "BETA!" sticker sits on the header corner.

## Files

- `index.html` — self-contained, no dependencies, works offline.
