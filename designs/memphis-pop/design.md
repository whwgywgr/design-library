# Memphis Pop — Festival Poster

The Memphis Milano look: white space invaded by confetti geometry — zigzag ribbons,
dot grids, triangles, half-circles and squiggles — all in bright primaries with chunky
black outlines, wrapped around a festival poster.

## Tokens

| Token | Value |
|---|---|
| Paper | `#ffffff` with scattered shapes |
| Primaries | red `#ff5252` · amber `#ffd740` · blue `#40c4ff` · green `#69f0ae` · pink `#ff4081` |
| Outline | 3px solid `#111` on shapes and cards |
| Type | system sans, 900-weight outlined display |

## Pieces

Poster header with outlined title → info chips → **live countdown** to the event
(days/hours/minutes/seconds, ticking every second) → lineup list with hover wiggle →
three ticket tiers → patterned footer.

## Files

- `index.html` — self-contained, no dependencies, works offline.
