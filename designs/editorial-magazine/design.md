# Editorial — Magazine Layout

Print journalism translated to the web: a serif masthead with hairline rules, a dateline, an oversized headline, a drop cap opening, measured two-column body text and an italic pull quote.

## Tokens

| Token | Value |
|---|---|
| Paper | `#fbfaf7` |
| Ink | `#1a1815` · secondary `#6e675e` |
| Rules | `#1a1815` double rule (masthead), `#d8d2c7` hairlines |
| Serif | Georgia, "Times New Roman" — headlines & body |
| Accent | `#8a2b1d` oxide red, links & kickers |

## Layout

Progress bar → masthead with dateline → lead story (kicker, giant headline, byline, drop cap, two-column flow, pull quote) → three related stories on hairline columns → colophon footer.

## Motion

A thin reading-progress bar fills as you scroll — the only ornament.

## Files

- `index.html` — self-contained, no dependencies, works offline.
