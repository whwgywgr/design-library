# Retro / Y2K — Nostalgia Page

The hand-made web of 2002, recreated with modern CSS: window chrome with beveled borders, tiled starfield, rainbow gradient WordArt, scrolling marquee, hit counter and a "best viewed" badge.

## Tokens

| Token | Value |
|---|---|
| Desktop | `#008080` teal (classic wallpaper) |
| Window | `#c0c0c0` silver with outset bevels, navy `#000080` title bar |
| Page inside | `#000033` starfield |
| Accents | `#00ff00` lime, `#ffff00` yellow, `#ff00ff` magenta |
| Type | "Comic Sans MS", Verdana, Times New Roman |

## Pieces

Fake browser frame → rainbow welcome → marquee → table layout with "about me" + guestbook → hit counter (persists in localStorage) → webring + best-viewed badges.

## Files

- `index.html` — self-contained, no dependencies, works offline.
