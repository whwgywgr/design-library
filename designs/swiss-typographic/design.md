# Swiss — Typographic Grid

International Typographic Style: mathematical grid, neutral type, objective photography
space and exactly one accent colour. Order is the aesthetic.

## Tokens

| Token | Value |
|---|---|
| Paper | `#ffffff` |
| Ink | `#111` · secondary `#777` |
| Accent | `#e30613` swiss red — one element at a time |
| Type | "Helvetica Neue", Helvetica, Arial — headlines 700 tight, labels 11px uppercase +0.18em |
| Grid | 12 columns, 24px gutter — press **G** to reveal it |

## Structure

Spec-sheet masthead → oversized lowercase display with a red full stop → three objective
text columns → numbered index (01–04) with hairline rules → coordinates footer.
