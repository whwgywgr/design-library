# Gradient Mesh — Vivid SaaS

The gradient is the design: four huge blurred colour fields drift behind the content while
the headline text itself is painted with a moving gradient. Minimal UI on top — the colour
does all the talking.

## Tokens

| Token | Value |
|---|---|
| Base | `#0b0b14` near-black |
| Mesh | magenta `#ff2ea6` · violet `#7c4dff` · cyan `#00e5ff` · amber `#ffb300`, blurred 100px |
| Headline | gradient text, animated hue shift |
| Surfaces | `rgba(255,255,255,0.04)` panels, 1px `rgba(255,255,255,0.1)` |
| Type | system sans, 400-weight display |

## Interaction

Blobs drift on their own and **follow the pointer** with soft parallax; stats count up on
view; the headline gradient slowly shifts hue.

## Files

- `index.html` — self-contained, no dependencies, works offline.
