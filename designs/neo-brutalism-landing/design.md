# Neo-Brutalism — Modern Landing

Not the 2016 brutalism in this library — the friendly revival: cream background, candy
colour blocks (lime, pink, cyan, yellow), 3px black borders, hard `6px 6px 0 #111`
shadows in colour, slight corner radius and a rotating sticker.

## Tokens

| Token | Value |
|---|---|
| Background | `#f5f1e8` cream |
| Ink | `#111` borders, shadows, text |
| Pops | lime `#b9ff66` · pink `#ff90e8` · cyan `#90e0ef` · yellow `#ffd43b` |
| Shadow | `6px 6px 0 #111`, grows to `10px 10px` on hover |
| Type | system sans, 750-weight headlines, highlighted marker spans |

## Pieces

Pill nav → hero with marker-highlighted headline + rotating ✺ sticker → lime marquee →
three colour cards that lift on hover → working FAQ accordion → black footer.

## Files

- `index.html` — self-contained, no dependencies, works offline.
